Authentication & User Management:
User Registration & Login: Implemented a secure account creation and login system to manage individual user profiles.
Seamless Session Management: Added a log-out feature, allowing multiple users to switch accounts without restarting the application.
Score Persistence: Integrated a user database/file system to store and track running total scores linked to each account.
User Interface:
Global Navigation: Added a standard menu bar to host essential features, navigation, and help resources.
Quiz Form Refactoring: Restructured the quiz interface into separate, dedicated forms for a cleaner and more modular workflow.
Reaction Test Optimizations: Relocated timer displays and reaction metrics for better visual balance, and implemented an automatic form reset upon test completion to streamline repeat attempts.
